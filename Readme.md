# Handwritten Digit Recognition CNN (Java)

A Convolutional Neural Network (CNN) built completely from scratch in Java without using deep learning libraries such as TensorFlow or PyTorch.

## Features Completed

- Matrix operations
- Tensor implementation
- Layer interface
- Identity Layer
- Fully Connected Layer
- ReLU Activation
- Softmax Layer
- Neural Network Architecture
